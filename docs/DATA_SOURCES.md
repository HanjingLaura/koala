以上记录发布日期为 2019-04-01。核验通过 FDC `/foods` API 按 ID 查询；能量取 nutrient number 208（kcal），蛋白质 203，脂肪 204，碳水 205。每条运行记录保留英文原名、ID、详情页与核验日期。新餐食保存当时的名称、热量、营养和来源快照；旧记录热量不重算。食谱仍只是搭配参考，没有宣称已计算整份营养。

官方 API 与许可：https://fdc.nal.usda.gov/api-guide/ 。数据为 CC0；页面已标明来源。

当前无需新增 Key。扩展为实时食物搜索时，需要申请自己的 FDC API Key，放在服务端，增加缓存、限流和状态匹配。不要在线上使用公共 DEMO_KEY。中国家常菜、餐馆和品牌食品需要另选有授权的数据源，不能把一道菜直接匹配为某个单一食材。

训练卡片直接嵌入官方 youtube-nocookie 播放器，并使用浏览器延迟加载；没有设置自动播放，不会启动计时或打卡。保留原作者和原链接，不下载或重新托管视频。精选视频嵌入不需要 YouTube Data API Key。嵌入资格、地区和网络会影响播放；上线前须在目标用户网络实播验证，oEmbed 成功不等于能完整播放。

播放器依据：https://developers.google.com/youtube/player_parameters 。若服务面向中国大陆，应准备可用的授权视频来源，不能只依赖 YouTube。
