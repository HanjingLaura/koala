## 字体调整版 · 2026-10-19

本版基于 `codex/daily-records`，独立保存到 `codex/typography-refresh`；原分支和原样式保留。`typography.css` 在 `styles.css` 后加载，只覆盖排版，不修改原样式文件或角色素材。后续调整集中修改这个文件；移除入口中的该样式引用即可恢复原排版。

中文标题改用与界面一致的无衬线字体，依次使用设备上的苹方、微软雅黑或其他中文黑体；英文保留本地 Manrope。收紧标题字距、统一字重，放大正文及辅助说明，并适配手机字号。跨设备中文字体外观会随已安装字体略有不同；不新增字体下载或外部请求。

团队讨论用网站原型 v0.2（2026-10-18）。核心体验：**中断后，还能继续**。用户表达今天的状态，Kora 给出可选调整，用户确认后同步今天、本周和站内提醒文案。

## 运行

无需安装依赖或构建。在仓库根目录执行：

```sh
python3 -m http.server 4179 --bind 127.0.0.1 --directory website
```

打开 http://127.0.0.1:4179 。拿到独立网站包的队友，请在解压后的 `website` 文件夹内执行 `python3 -m http.server 4179 --bind 127.0.0.1`。字体、图片和 GSAP 均包含在包内；作者频道链接需要联网。请通过 HTTP 预览，浏览器直接打开文件时本地保存行为可能不同。

## 页面与演示路线

- **今天**：状态入口、计划调整、确认前后对比、撤销、完成标记、真实周历及每日历史。
- **饮食**：六种示例食物的份量换算、餐食记录保存/删除、三份搭配灵感。
- **运动**：有氧/力量/舒展/不跳跃筛选、确认后替换今天安排、作者频道参考链接。
- **聊聊**：预设情境回复；没时间、中断、自责、疲劳可进入调整流程；疼痛情境不推荐继续训练。
- **我的档案**：昵称与生活偏好、本地数据清除、旧版无日期记录查看；记录“体型联动”的后续讨论方向。

建议演示：`今天没时间 → 做一点就好 → 查看30分钟变10分钟 → 确认 → 回到今天 → 刷新 → 撤销`。另可展示 `好几天没记录 → 安心休息`，或在周日改期到下周一，再翻到下周查看。

## 实现边界

这是可点击的前端交互原型，不是完整健康产品。无账号、后端、真实 AI、图片识别、系统通知或定时消息。聊天为关键词触发的固定回复，提醒只改变界面上的安排文字。食物值为演示值；训练卡片不是核验过的具体视频，时长属于演示安排，外链仅到作者频道。未实现社群、照片评估、真实个性化营养处方或训练推荐。

昵称、偏好、每日计划、餐食及调整记录使用此浏览器的 localStorage；聊天只在页面内存中保留。日期采用设备本地时区，周一为每周起点，可查看上下周并打开每日记录。新的一天按当前时长偏好创建初始安排，已有改期安排优先保留；旧日记录不自动标完成或补做。页面重新获得焦点、恢复可见或每30秒检查跨天，跨天时关闭旧确认框，避免把昨天的操作写到今天。

改期会保留今天的改期记录，并预约真实明天（含跨周、月、年）。明天已有安排时不覆盖；撤销会恢复涉及的两个日期，目标记录后续发生变化时拒绝撤销。餐食和完成标记按日隔离，周历只展示实际保存的数据，已移除模拟加班历史和虚构的已记录日期。

旧版无日期的计划、餐食和历史整体保留在“旧版无日期记录”存档中，昵称和偏好继续使用，不猜测记录日期、不自动计入今天。升级仍使用原 localStorage 键，内部 schema 从1迁到2；旧版代码无法读取新版记录，回退前应保留新版存储副本。清除数据会清除所有日期及旧存档。偏好保存不自动改写已有计划。没有服务端备份、跨设备同步或多标签页冲突合并。历史仅查看，暂不提供补录、任意未来排课或基于历史的自动建议。

**新方向：Kora 和用户一起变化。** 建议自愿开启，按长期趋势缓慢变化，不用当天体重驱动；所有体型保持同等可爱与陪伴待遇。当前只保留概念说明，尚未实现体型识别、数据采集和形变。

## 设计与代码

奶油白、鼠尾草绿和浅桃色；Manrope 正文搭配站酷小薇标题；GSAP 入场和轻微呼吸动作，尊重减少动态效果设置。手机端使用底部导航。

- `index.html`：应用壳与弹窗、导航。
- `app.js`：页面模板、每日状态交互和本地保存。
- `daily.js`：本地日期运算、按日存储、旧版迁移、改期与撤销。
- `daily.test.cjs`：运行 `node --test website/daily.test.cjs` 验证跨天及迁移边界。
- `styles.css`：视觉、响应式布局与减少动态效果适配。
- `assets/`：字体、Kora 和 favicon。
- `vendor/gsap.min.js`：GSAP 3.14.2，保留原许可标头。
- `ASSETS.md`：素材来源与候选图状态。

开发基于 `Cora` 分支，原型以 `main` 的 `b1ac47a` 为基础。代码存放在本分支的 `website/` 目录。每日记录改进在 `codex/daily-records` 独立分支提交 PR 到 `Cora`，经团队审查；主分支仍需 Cora 批准后合并。GitHub 仓库存放源代码，不等于网站已部署；当前没有启用线上托管。不要把 ZIP 提交进代码仓库，应提交解压后的 `website/` 文件夹。
