# Kora · 你的生活搭子 / Your everyday companion

团队讨论用前端原型 v0.6（2026-10-19）。核心体验：中断后还能继续；先选一只合拍的 Kora，再建立自己的生活档案。

v0.3.3 将淡淡型和温柔型也调整为短腿、小脚掌、收拢坐姿，保留原有表情与运动装。四种性格统一使用修订比例：淡淡 / 温柔为 `*-sport-v2.png`，毒舌 / 暴躁沿用 `*-sport-v4.png`。

## v0.6 合并说明

以远端 Cora `efd92452eee201bff29d6c7d8b9259fbb3ad3035` 为合并目标，保留真实日期的计划、餐食、历史、跨日改期与撤销保护；界面沿用本地已确认的双语、四种性格、排版和动画。

存储统一升级为 schema 3，兼容团队的 schema 2 按日记录及本地预览的 schema 2 无日期记录。无日期旧数据单独存档，不猜测日期；原昵称、身高体重、偏好、性格和语言继续保留。团队原 typography.css 文件保留追溯，但入口采用本次已确认的排版。

本次更新直接替换仓库已有 website/ 目录中的相关文件，承接 Cora 分支现有提交，不新增版本目录或提交 ZIP。

## v0.5.1 动作收敛

按用户实际观看反馈，保留已认可的眨眼。呼吸横向幅度从15%降到3%，纵向位移同步缩到原来的1/5，周期从4.8秒放慢到6秒。耳朵横纵幅度缩到原来的1/5，回弹减弱，单次动作由0.65秒放缓到0.8秒；首次12秒出现，之后间隔20 / 24秒。手动打招呼仍可立即回应，使用同样的小幅耳动。

## v0.5 首页动态陪伴（初版参数，现由 v0.5.1 调整）

- 首页四种性格都支持胸腹呼吸、完整眨眼、单耳动作。使用 GSAP 时间线与 WebGL 局部变形，保留原 PNG 作为回退。
- 呼吸周期 4.8 秒，胸腹局部横向膨胀系数 15%；脚部与五官不在呼吸作用区。耳尖最大位移约整图高度 5.25%（约耳高 15%），耳根平滑衰减，非整张图缩放。
- 首次眨眼约 1.35 秒、首次单耳动作约 2.2 秒，后续错开节奏，包含偶发双眨。新增闭眼素材只在两个眼睑附近采样，不替换整张角色图。
- 「打个招呼」立即触发眨眼 / 单耳回应；「暂停动作」恢复静态原图。系统减少动态效果、切后台、离开视口时暂停，切页时释放时间线、监听器与 GPU 资源。
- WebGL / 素材不可用时显示原图。代码与时间线测试通过，v0.5.1 动作参数已获用户实看认可；v0.6 已在实际浏览器验证页面与交互，见 QA.md。

## v0.4 字体与交互细节

- 中文展示标题使用本地站酷小薇，正文保留系统中文字体；英文与数字使用本地 Manrope，英文展示标题使用设备 Georgia 衬线字。
- 首页两行标题依次展开，重点词下的弧线随后展开；考拉和说明以短距离进入。首页加入淡色 Kora 字标，保留简洁留白。
- 性格卡片支持悬停 / 键盘聚焦时轻微抬起，离开后恢复。切换页面或重渲染清理动画与事件；同页保存、打卡不重播入场。
- 尊重系统减少动态效果设置；GSAP 不可用时内容仍直接显示。未新增滚动劫持或持续循环动画。

## v0.3 功能

- 全站中文 / English 切换：首次设置、五个功能页、弹窗、提示、性格台词和预设聊天回复。用户自己输入的昵称、聊天原文不做自动翻译。
- 首次进入必须先选性格，再填写昵称、身高（cm）、体重（kg）、运动偏好（多选）、可用时间与生活目标；保存后直接进入首页，同一份资料出现在档案里。
- 四种性格：淡淡型 Chill（绿色）、毒舌型 Witty（深灰）、暴躁型 Fiery（暖橙）、温柔型 Gentle（粉色）。均为运动上衣＋短裤＋发带，同一 Kora 身份的候选衍生图。
- 性格影响首页问候、饮食 / 运动页一句话、聊天头像与情境回复、完成反馈，以及少量强调色。其他性格主要出现在选择界面，不持续弹窗或漂浮。
- 档案里可以更换性格和修改基本资料，点击保存后同步。切换语言保留当前资料表单和计划确认方案。
- 身材羞辱、补偿性节食、忍痛训练不属于任何性格；受伤情境使用统一的认真回应。

## 本地运行

无需安装依赖或构建。在仓库根目录：

```sh
python3 -m http.server 4179 --bind 127.0.0.1 --directory website
```

打开 http://127.0.0.1:4179 。独立 ZIP 包请解压后在 `website/` 内运行 `python3 -m http.server 4179 --bind 127.0.0.1`。

图片和 GSAP 均在包内，字体由包内文件和设备系统字体组成；外链作者频道需要联网。请使用 HTTP，避免 `file://` 的存储差异。

## 演示路线

1. 选粉色温柔型 → 填写虚构演示资料 → 保存 → 首页出现选中的 Kora。
2. 档案里确认资料已同步；换毒舌型、保存 → 首页与聊天同步换语气。
3. 聊天输入“今天只有10分钟” / “I only have 10 minutes” → 查看可选安排 → 确认前后对比 → 确认 → 首页与周历同步 → 撤销。
4. 随时切换中文 / EN，刷新后仍保留语言、性格和已保存的资料。
5. 档案 → 清除本地数据 → 二次确认 → 回到首次选择流程。

五页：今天（计划、周历、调整 / 撤销）、饮食（六种示例食物与记录）、运动（筛选与替换计划）、聊聊（双语情境回复）、档案（性格、资料与本地数据管理）。

## 数据与实现边界

这是可点击的前端原型，没有真正登录账号、后台、真实 AI、云端同步或用户间数据共享。所谓首次进入是浏览器本地 onboarding，不是账号注册。

`localStorage` 保存资料、语言、演示计划、餐食和调整记录。身高体重只做档案记录，不计算减重期限、处方或自动形变。聊天只在当前页面内存中保留。清除浏览器数据或更换设备后不保留。保存失败会明确提示“本次页面保留”。

旧 v0.1 / v0.2 状态会保留现有计划和餐食，并要求补齐性格与基本资料。新旧使用同一个存储键 `kora.preview.v1`，数据结构升级为 schema 2。表单草稿在同次页面内切换语言 / 返回上一步时保留，未提交草稿刷新后不保留。

食物值与训练卡片是演示内容，外链到作者频道，非已核验具体视频；运动偏好只展示，不声称完成适用性评估。周历仍是固定周三示例。提醒只是页面文字，没有系统通知。未实现社群、照片评估、开放式 AI 对话、自动体型联动或跨天餐食归档。

## 设计和资源

延续 v0.2 白底、系统无衬线字体、留白和简洁顶部导航；手机底部导航。布局研究参考 [Apple 健康页面](https://www.apple.com.cn/health/)，没有复制其素材或下载专用字体。GSAP 仅用于短距离淡入，尊重减少动态效果设置，无持续漂浮。

- `app.js`：双语文案、四种性格、页面、数据迁移与交互。
- `styles.css`：视觉、性格选择、响应式布局。
- `assets/kora-*-sport.png`：四张运动装性格图；`assets/persona-prompts.json` 保存内置 imagegen 生成提示词。
- `ASSETS.md`：来源、许可与候选素材状态。
- `tests/state.test.cjs`：资料验证、双语覆盖、性格区别、计划转换、旧数据迁移与文本转义测试。
- `QA.md`：实际浏览器验证记录和未验证范围。

运行检查：`node --check website/app.js`、`node website/tests/state.test.cjs`。

本地工作分支为 `Cora`。本轮 v0.2 / v0.3 修改尚未提交或推送；主分支没有修改。合并 `main` 需 Cora 批准。源代码存放在 `website/`，ZIP 仅供分享预览，不提交进代码仓库。
