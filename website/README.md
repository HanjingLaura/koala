# Kora · 你的生活搭子 / Your everyday companion

团队讨论用前端原型 v0.8（2026-10-19）。核心体验：为减脂路上想半途而废的人，把今天调成做得到的样子。不用重新开始，我们接着来。

## v0.8 · 你的生活人格

- 首次体验：六道情境题 → 人格结果 → 选择搭子语气 → 基本资料。已有用户可从首页或档案主动进入，不强制重新设置。
- 四种生活类型：省电型 LAZY、热启动型 SPARK、忙碌型 BUSY、心情型 FEEL。与淡淡、毒舌、暴躁、温柔四种陪伴语气独立。
- 第 1 / 2 / 5 题匹配类型，同分时参考第 1 题；第 3 / 4 / 6 题采集运动、可用时长与时段。规则可解释，不是 MBTI 或心理测评，不用体重判断人格。
- 保存结果同步 `profile.lifestyle`、运动和时长偏好。重测保留计划、餐食、历史和搭子语气。档案修改运动偏好会影响首页推荐。
- 首页省电型建议 1–2 分钟、热启动型 5 分钟、忙碌型最多 10 分钟，心情型先询问状态。采用建议需确认；支持按日保存、完成和撤销。休息日或已完成的日子不追加推荐训练。
- 测试支持中英文切换、上一题、重测；本标签页草稿通过 sessionStorage 保留刷新进度。昵称必填，身高和体重可稍后补充。
- 人格结果与档案可导出本地 PNG 分享卡，不含姓名、身高或体重。时段仅记录偏好，不会开启后台通知。
- 新插画沿用原版身份：四种生活人格均使用 v4；红蓝修正耳朵与脸颊，绿粉随后以红蓝 v4 为参考统一耳朵比例。旧陪伴角色与眨眼动画不变。新图作为本次原型素材提交审核，不替换角色资产库主参考。

English: A six-question bilingual preference quiz introduces four lifestyle types, separate from Kora’s companion voice. Results sync with Profile and home suggestions. Existing records stay intact; adopting a suggestion requires confirmation. Measurement fields are optional. Results can be exported as a PNG without personal metrics. This is a local prototype, not a psychological test or a real notification service.

## v0.7 · 断了，也接得上

首页以“今天还剩多少电”为主要入口：有点劲儿、只剩一点电、今天撑不住。选择状态 → 说说原因 → 确认安排 → 记录小行动或自我照顾；确认前不改写已有计划。

- 有点劲儿保留原安排；低电量可以选走动2分钟或舒展1分钟；休息取消今天未完成的训练与提醒，保留餐食。
- 确认后首页收成一件事；完成后收起加任务的入口，Kora 的场景颜色、状态与回应随选择变化。沿用已确认的四套运动装与眨眼、呼吸、耳动，没有改动角色五官或身体比例。
- 四种性格提供不同的“接你回来”回应；“我又想放弃了”可进入对话再接到小行动。
- “回来过的路”只展示本地实际确认的安排、完成的行动、自我照顾与餐食记录，不把打开页面或自动生成的计划算作行动，不展示未来预约和无日期旧档案。空白日不代表失败。
- 有足够真实完成记录时，展示两次记录之间的空白天数；只有本次空白比上次短才展示比较，不编造进步。
- 已完成的行动受到保护。撤销会恢复原计划及当天陪伴状态；日期或计划变化时拒绝旧确认，跨日预约保护继续保留。
- 饮食、运动和周历保留在首页下方的可展开区域，导航入口仍可直接使用。

新增状态保存在 schema 3 的对应日期下（`day.comeback`），继续兼容现有记录。v0.7 与 v0.8 一同通过 Cora → main 的 PR 提交审核，不自动合并或部署。

## 当前功能

- 中文 / English 切换覆盖首次设置、五个功能页、弹窗、提示、性格台词与预设聊天回复。用户填写的昵称和聊天原文不自动翻译。
- 首次进入先测生活人格、再选陪伴性格，补充昵称、可选的身高体重和生活目标；运动与时间偏好由测试预填，可修改；保存后进入首页，同一份资料可在档案里修改。
- 四种运动装 Kora：淡淡型 Chill（绿色）、毒舌型 Witty（深灰）、暴躁型 Fiery（暖橙）、温柔型 Gentle（粉色）。性格影响问候、情境回复、完成反馈与少量强调色。
- 五页：今天（计划、周历、调整 / 撤销）、饮食（六种示例食物与记录）、运动（筛选与替换计划）、聊聊（双语情境回复）、档案（性格、资料与本地数据管理）。
- 周历按设备本地日期展示，支持上下周浏览和每日详情；计划、餐食、完成状态及调整记录按日期保存。跨天后保留过去的记录。
- 调整计划前展示确认步骤；改到明天会预约真实的次日，包括跨周、跨月情况。已有目标日安排不会被覆盖；撤销也会保护目标日后续新增的数据。
- 所有性格都遵循同样的边界：不羞辱身材，不鼓励补偿性节食或忍痛训练；受伤情境使用统一的认真回应。

## 当前视觉与动作

中文展示标题使用本地站酷小薇，正文使用系统中文字体；英文与数字使用本地 Manrope，英文展示标题使用设备 Georgia 衬线字。保留白底、留白、顶部导航与手机底部导航。布局研究参考 [Apple 健康页面](https://www.apple.com.cn/health/)，未复制其素材或下载专用字体。

团队的独立字体方案 `typography.css` 保留供比较与追溯，当前 `index.html` 不加载它；页面采用上述已确认的排版。

- 当前角色图为 `kora-calm-sport-v2.png`、`kora-gentle-sport-v2.png`、`kora-snark-sport-v4.png`、`kora-fiery-sport-v4.png`，使用修订后的短腿、小脚掌与收拢坐姿。
- 首页通过 GSAP 时间线和 WebGL 局部变形实现呼吸、眨眼和单耳动作。呼吸横向幅度为3%，周期6秒；耳动首次在12秒出现，之后间隔20 / 24秒，单次动作约0.8秒。保留用户已认可的眨眼效果。
- 闭眼素材只在眼睑附近采样；「打个招呼」触发回应，「暂停动作」恢复静态原图。WebGL 或素材不可用时回退为原图。
- 首页标题分行进入并展开弧线，性格卡片悬停 / 键盘聚焦时轻微抬起。系统减少动态效果时使用静态呈现；陪伴动作在后台或离开视口时暂停，切页时释放相关资源。

## 数据与实现边界

这是可点击的前端原型，没有账号登录、后台、真实 AI、云端同步或用户间数据共享。首次设置是浏览器本地流程，不是账号注册；聊天是预设情境演示。

`localStorage` 使用存储键 `kora.preview.v1`，当前数据结构为 **schema 3**，保存资料、语言、按日计划、餐食和调整记录。兼容团队 schema 2 的按日记录，以及旧 schema 1 / 2 的无日期记录。无日期计划与餐食完整保留在独立旧记录存档中，不猜测日期或自动计入今天；原有资料继续保留，缺少必要信息时需要补齐首次设置。

聊天仅保留在当前页面内存中；未提交的资料草稿在同页切换语言或返回上一步时保留，刷新后不保留。清除浏览器数据或更换设备后，本地记录不会随账号恢复。保存失败会提示“本次页面保留”。多标签页并发修改的自动合并尚未实现；回退旧版代码前应保留存储副本。

食物数值和训练卡片是演示内容；运动外链指向作者频道，并非逐条核验过的训练视频。运动偏好作为档案记录，不代表完成了个体适用性评估。身高、体重不用于生成减重处方、目标体型、减重期限或自动改变考拉体型。

提醒仅为页面文字，没有系统通知。尚未实现社群、照片评估、开放式 AI 对话及自动体型联动。

## 本地运行

无需安装依赖或构建。在仓库根目录执行：

```sh
python3 -m http.server 4179 --bind 127.0.0.1 --directory website
```

打开 http://127.0.0.1:4179 。独立 ZIP 包请解压后，在 `website/` 内执行 `python3 -m http.server 4179 --bind 127.0.0.1`。

图片、GSAP 和本地字体均随代码提供；外链作者频道需要联网。请使用 HTTP，避免 `file://` 的存储差异。

## 演示路线

1. 完成六道趣味情境题 → 查看生活人格 → 选粉色温柔搭子 → 填写虚构昵称（身高体重可留空）→ 保存 → 首页出现人格建议与选中的 Kora。
2. 档案里确认资料同步；换毒舌型并保存 → 首页与聊天同步换语气。
3. 首页选“只剩一点电” → 选“我又想放弃了” → 选择一个小行动 → 确认 → 首页与周历同步 → 撤销或完成；也可选择休息，记录一次自我照顾。
4. 浏览上一周 / 下一周，点击日期查看记录；改期前确认目标日已有安排会得到保护。
5. 切换中文 / EN 并刷新，确认语言、性格和已保存资料保留。
6. 档案 → 清除本地数据 → 二次确认 → 回到首次选择流程。

## 代码与验证

- `app.js`：双语文案、四种性格、页面、资料与计划交互。
- `lifestyle.js`：趣味测试评分、结果、偏好与首页建议。
- `lifestyle.css`：测试、结果与生活人格卡片布局。
- `comeback.js`：状态选择、确认与完成、真实路径和记录间隔计算。
- `daily.js`：本地日期、按日记录、迁移、跨日改期与撤销保护。
- `companion.js`：首页陪伴动画、静态回退及资源清理。
- `styles.css`：当前排版、性格选择与响应式布局。
- `ASSETS.md`：素材来源、许可与候选素材状态；生成提示词位于 `assets/persona-*-prompts.json` 等文件。
- `SHA256SUMS.json`：网站文件校验清单，不包含清单自身。
- `QA.md`：各版本验证记录及未验证范围；当前状态参见 v0.8 提交检查部分。

在仓库根目录运行现有检查（需要 Node.js）：

```sh
node --check website/app.js
node --check website/companion.js
node --test website/daily.test.cjs website/tests/*.test.cjs
```

25 项检查覆盖人格评分与偏好联动、中断后继续、日历边界、改期与撤销、双语状态、资料验证、数据迁移及实际 GSAP 时间线。v0.8 已进行桌面与 390px 浏览器主要流程检查（见 QA.md）；动画观感依据用户实看反馈，静态截图和自动测试不代替完整跨浏览器、真机或性能验收。
