# Kora 角色手册

## 名称与身份

正式名称仅为 **Kora**，来源为 Koala × Cora。不得自行使用 Corala、Koko、KoKo、CoraKo 或 Kora Koala。品牌排版特殊大小写需单独批准。

Kora 是独立角色，不是 Cora 的动物化替身。Kora 是一只小型办公室考拉，柔软、克制、善于观察、略有怨气、安静地评判、能干、疲惫、有条理、情绪能量低。可爱源于大毛耳、紧凑姿态、小动作和比例，而非主动卖萌。

既有定义：**Kora — soft fur, low battery, strong opinions.**

## 外形优先级

脸部结构 → 眼睛大小与间距 → 鼻子 → 耳朵轮廓 → 毛发分布 → 头身比例 → 身体轮廓 → 左侧 K → 表情 → 衣服 → 道具 → 环境。

主脸为 KOR-ID-001；完整五官比例以原图为准，不编造比例参数。保持宽软脸、低存在感小嘴、宽圆深色鼻子、大毛耳及短小紧凑四肢。不得因为动作、衣服或“更可爱”而改变身份、视觉年龄或扩大眼睛。没有外露突起尾巴（历史明确规则 E17）；九视角存在待核对例外，见待确认事项。

灰色体毛、浅色口鼻与胸部；现行规则推荐冷中灰，历史制作交接也曾使用暖中性灰。保留已批准原图与场景光照，不以文字色温强行统一调色；尚未建立统一数值色板。不得由照片像素推导新的固定 HEX 色值。

耳朵随头骨朝向转动。背面主要见灰色耳背及外缘毛发，不能仍展示朝向镜头的大块粉色内耳。

## 永久 K 毛色标记

标记只在 **Kora 自身解剖学左侧躯干的侧腰**，低于下肋、高于髋，远离腹部中心和脊柱，不在大腿。Option B 的位置已经批准，不重开 A/B/C 选择。

只有一个手写、略带连笔感的 K：清晰但不几何化的竖笔、自然相连的两条斜笔，克制、柔和、无装饰。不能变成 X/R/H、随机斑纹、分叉树枝；不用衬线、黑体、哥特体、花体、涂鸦或商标字形，不加心、星、圆、下划线、冠或其他字母。

目标高度约为可见躯干高度的 8–10%；自然色素约比邻近毛发深 12–18%，为略深冷炭灰，不能纯黑、彩色或发光。以上为设计目标，本库没有把渲染照片测量成物理达标证明。

标记与周围毛发具有相同材质、毛长、方向、深度和渲染方式；边缘由毛丝柔和过渡，仍能在第二眼读出 K。不能呈现油墨、纹身、刺绣、贴花、剃毛、伤疤、烧痕、金属或凸起。

镜像不改变角色解剖学：不能把左侧 K 镜像成右侧。左3/4、左侧面与背左角度可自然露出，正脸、右侧、蜷坐、遮挡或穿衣时可以完全看不见。不得扭曲姿势以展示 K，也不得因镜头远而放大。

KOR-KM-001/002/003 分别支持位置、侧面、背左验证；形状等物理特征已有冻结记录，但尚未登记统一的 `kora_kmark_master` 资产。此登记问题不是重设计授权。

## 表情与动作

表情通过眼睑开合、注视方向、嘴角、微小头角度和肩部张力变化。Neutral 平静略呆；Monday 眼睑稍低、视线略下；Annoyed 轻微侧视和不悦；Friday 眼神略亮、嘴角微升。禁止大笑、露齿、夸张愤怒、闪亮大眼、腮红、皱纹或眼袋强化。疲惫不等于衰老。

已批准动作包含打字、捧杯、趴桌、后靠、蜷坐及抱包。身体短小、自然支撑；坐姿必须读得出骨盆和腿受到椅面支撑，不能悬空或像站在椅上。爪子与键盘、杯子、包的接触应合理，不长成人手或成人四肢。

淡淡笑九视角获得表情保存批准，但尾部细节有待核对，暂不进入默认生成参考包。

## 衣着与办公室生活

当前签名衣着：低饱和柔和蓝色卫衣，帽子放下，两条短抽绳，胸前一片简洁细长的桉树叶。以 KOR-WD-002 为当前面料基准：干净、新、柔软、哑光、均匀蓝色棉绒，不带浅色斑点、做旧、粗花或压纹感。

衣服覆盖左侧腰部时自然 K 完全隐藏，不自动复制到衣服、包或其他物体上。桉树叶是已批准衣服图案，和未来 Graphic K 品牌系统分开。

工位、咖啡休息、加班、通勤、会议、小憩、下班电梯、周五离开及雨天是已存在场景。环境光可改变照片观感，但不得借机重设计毛色、脸或衣着。
